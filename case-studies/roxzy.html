Roxzy Bakery & Catering

A responsive catering website with data-backed enquiries, managed media and protected staff interactions.

Cloudflare WorkersD1R2DrizzleValidationRate limiting

THE PROBLEM

What needed solving.

A customer-facing site has to do more than look appealing. Requests need to be captured, media needs reliable storage and staff-facing functionality needs access controls.

MY CONTRIBUTION

What I worked on.

  • Built customer-facing experiences and structured enquiry workflows.
  • Worked with Cloudflare Worker deployment, D1 database migrations and R2 media storage.
  • Implemented protected administration concepts, request validation and rate-limiting measures for sensitive endpoints.

SYSTEM DESIGN

How the system fits together.

01Visitor
02Cloudflare Worker
03D1 / submissions
04R2 / media

Architecture illustration — simplified explanation, not a production infrastructure screenshot.

The Worker serves the site and handles server-side functionality. Durable submission records use D1; media is stored separately in R2. Staff actions and submission endpoints are protected with authentication, validation and rate limiting.

ENGINEERING JUDGMENT

Decisions and trade-offs.

01

Separate data and media

Keep transactional records in a relational database and uploaded images in object storage.

02

Protect mutation endpoints

Validate inputs and restrict staff-only functionality instead of relying on hidden controls.

03

Deliver a usable experience

Support small screens, clear customer journeys and operational features such as enquiry and tracking flows.
